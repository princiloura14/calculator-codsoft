## 📖 Project Overview
This is a simple Calculator application developed using **Python**.  
The project performs basic arithmetic operations including addition, subtraction, multiplication, and division.

It was built using **Visual Studio Code** as part of my Python practice to strengthen programming fundamentals and logical thinking skills.

- ➖ Subtraction

- ➗ Division
- User-friendly input handling

- Clean and simple logic implementation

💡 How It Works
The program asks the user to choose an arithmetic operation.

It takes two numerical inputs from the user.

Based on the selected operation, it performs the calculation.

The result is displayed in the terminal.

The program handles invalid inputs and division-by-zero errors gracefully.
